# Todo Test

Небольшой todo проект для тестирования установки и работы mauli.

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

Откроется на http://localhost:3000

## Стек

- Vanilla JS (без фреймворков)
- localStorage для сохранения задач
- http-server для локального запуска

## Возможности

- Добавление / удаление задач
- Отметка выполнения
- Фильтры: все / активные / выполненные
- Очистка выполненных
- Сохранение между перезагрузками страницы
